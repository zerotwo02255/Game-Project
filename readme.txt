# 🎮 My Game Journey

A personal gaming tracker web application for managing and tracking my gaming journey.

## 📌 About

My Game Journey allows me to keep track of the games I want to play, the games I'm currently playing, and the games I've completed or dropped.

Game information can be searched through the RAWG API and added to my personal game library.

## ✨ Features

- 🔎 Search games using the RAWG API
- ➕ Add games to my library
- 📋 Bucket List
- 🎮 Playing
- ✅ Completed
- ❌ Dropped
- 📊 Track game progress
- ⭐ Rate games
- 📝 Add personal notes
- 📅 View release dates
- 🖼️ Game cover images
- 📖 Game details page
- ✏️ Edit game information
- 📸 Upload personal screenshots for each game
- 🗑️ Delete uploaded screenshots
